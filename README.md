
# Tejashwini J - Personal Portfolio

## About

This is my personal developer portfolio website built using
HTML, CSS and JavaScript.

The portfolio introduces my education, technical skills,
projects and contact information.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Features

- Responsive website design
- Home and About sections
- Technical Skills section
- Three project showcases
- Contact information
- Mobile navigation menu
- Dark and Light theme toggle
- Smooth scrolling

## Project Structure

my-portfolio/
- index.html
- css/style.css
- js/script.js
- images/
- README.md

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. View the portfolio in your browser.
